# 190x4 Bloodmoon

Тема оформления Steam: чёрная бумага, тушь, багровый серп и цепи. Работает без Millennium и без DLL внутри Steam.
Один exe ставит себя в профиль пользователя и подключается к локальному порту отладки клиента.

## Как устроено

- `src/client.css` окна клиента. Классы пишутся как `{{Имя}}` или `{{Имя@Сосед}}`, их текущие хеши берутся из реестра CSS-модулей живого Steam.
- `src/web.css` магазин и сообщество.
- `loader/recolor.js` выполняется в окнах: шторка до применения темы, перекраска, скрытие Big Picture.
- `loader/resolver.js` читает реестр классов.
- `app/` программа на .NET Framework 4.8 (есть в Windows 10 и 11): подключение к Steam, локальный сервер стилей для сайтов, установка, обновления, значок в трее.
- `build.mjs` собирает `out/`: шрифты и картинки встраиваются в CSS. Программа встраивает `out/` в exe.

## Сборка

```bash
node bloodmoon/build.mjs
dotnet build bloodmoon/app/Bloodmoon.csproj -c Release
```

На VPS не собираем: только в GitHub Actions или на Windows.

## Запуск

- `190x4-Bloodmoon.exe` окно установки.
- `--agent` фоновая работа.
- `--uninstall` окно удаления.

Установка копирует exe в `%LOCALAPPDATA%\190x4-Bloodmoon`, создаёт `.cef-enable-remote-debugging` в папке Steam (единственный запрос UAC), добавляет автозапуск и перезапускает Steam.

## Обновления

Тег `bloodmoon-vX.Y.Z` запускает `.github/workflows/bloodmoon.yml`: сборка, подпись, релиз и `latest.json` в служебном релизе `bloodmoon-latest`. Программа проверяет его через минуту после запуска и раз в 6 часов и ставит новый exe только при совпадении SHA-256 и подписи ECDSA P-256. Закрытый ключ хранится в секрете `BLOODMOON_UPDATE_KEY` (PEM в base64), копия на сервере. Его потеря означает, что установленные копии перестанут обновляться.

## Безопасность

Порт отладки работает без пароля и слушает только `127.0.0.1`: программы на этом ПК могут управлять клиентом Steam.
