# 190×4 — Steam Theme · Design Reference (Millennium)

Полный визуальный редизайн десктоп-клиента Steam в фирменном стиле **190×4** — киберпанк
command-center, красный неон по графиту. Тёмная тема. Поставляется как набор
**HTML-референсов** + готовый `theme.css` с токенами и примитивами компонентов.

> Документ самодостаточен: разработчик, не участвовавший в дизайне, должен суметь
> реализовать тему только по этому README + приложенным файлам.

---

## 1. Что это за файлы (важно прочитать первым)

Файлы в бандле — это **дизайн-референсы, собранные на HTML/CSS**. Это прототипы,
показывающие желаемый вид и поведение, **а не готовый код для прямого копирования** в
продакшн.

**Целевая среда — это тема Millennium для клиента Steam** (https://github.com/SteamClientHomebrew/Millennium).
Millennium инжектит CSS (и опционально JS) в окна Steam, построенные на **CEF / Chromium 126**.
Steam рендерит свой UI обычным DOM с собственными CSS-классами (хешированные имена вида
`._3Yc...`, плюс «дружелюбные» классы вроде `gamepadcontextmenu_…`, `library_…`).

**Задача разработчика:**
1. Взять токены и стили из `theme.css` как **источник правды по визуалу**.
2. Снять **актуальные селекторы** Steam через встроенный DevTools (`Millennium → включить
   разработческий режим`, либо CEF debugger на `localhost:8080`).
3. Переписать наши `.x4-*` стили на реальные селекторы Steam в `webkit.css` темы.
4. Там, где нужна перекомпоновка DOM или новые элементы (наш кастомный логотип, бейджи) —
   использовать `webkit.js` хук Millennium.

То есть HTML-референсы **воспроизводятся** в среде Millennium, а не отгружаются как есть.

### Структура реальной темы Millennium (что должно получиться на выходе)
```
steam/themes/190x4/
├── theme.json        # манифест: какие css/js куда инжектить (см. §9)
├── webkit.css        # основной стиль (сюда переносится содержимое theme.css → под селекторы Steam)
├── webkit.js         # (опц.) DOM-хуки: вставка лого-вордмарка, glitch-разметки, иконок
└── assets/
    └── fonts/        # (опц.) локальные Orbitron / Saira, если не тянуть с Google Fonts
```

## 2. Fidelity

**High-fidelity (hifi).** Финальные цвета, типографика, отступы, состояния и
микро-взаимодействия заданы точно. Воспроизводить **пиксель-в-пиксель**. Все значения —
в `theme.css` (`:root`) и продублированы ниже в §6.

## 3. Дизайн-принципы бренда (НЕ нарушать)

Это правила, отличающие тему от дефолта. Они важнее, чем буквальное повторение раскладки.

1. **Красный `#ff2530` = успех / активно / connected / «Играть» / в игре.** Это инверсия
   привычной семантики (где зелёный=успех). Кнопка Play, активный таб, прогресс загрузки,
   статус «в игре», connected-индикаторы — всё красное с неоновым glow.
2. **Зелёный `#38e07b` — ТОЛЬКО точка статуса «в сети».** Больше нигде. Статус «в игре» —
   красный, не зелёный.
3. **Шрифт Orbitron — ТОЛЬКО логотип и верхняя навигация** (Магазин/Библиотека/Сообщество).
   В тексты, кнопки, списки его не пускать — там Saira.
4. **Glitch-эффект (RGB-расслоение) — ТОЛЬКО на логотипе.** Нигде больше.
5. **Графитовый фон** (`#07090d`–`#11151d`), hairline-границы (`rgba(255,255,255,.06)`),
   острые углы (радиусы 2–5px, не больше). Никаких мягких «материальных» теней-облаков —
   тени резкие + неоновый glow от акцента.
6. **Минимализм данных.** Не плодить лишние числа/иконки/бейджи. Меньше — лучше.

## 4. Логотип (выбранный знак — концепт «Glitch»)

Заменяет надпись «STEAM» в левом верхнем углу.

- **Текст:** `190×4`. «190» — белое `#fff`; «×4» — тёмно-красное.
- **Шрифт:** Orbitron 900, `letter-spacing:1–2px`.
- **Glitch:** два хроматических «призрака» через `::before`/`::after` (`content:attr(data-t)`,
  `mix-blend-mode:screen`): красный `#ff2530` сдвинут влево + обрезан снизу
  (`clip-path:inset(0 0 55% 0)`), циан `#27e0ff` сдвинут вправо + обрезан сверху
  (`clip-path:inset(48% 0 0 0)`). На `:hover` сдвиг призраков усиливается.
- **Двухрежимный красный для «×4» (ради читаемости в углу):**
  - крупно (≥28px, hero/дизайн-система): `#8c0d14` (глубокий, `text-shadow:0 0 7px rgba(140,13,20,.5)`)
  - мелко (<28px, титулбар/favicon): `#c01622` + `text-shadow:0 0 5px rgba(192,22,34,.55)`
- **Разметка:**
  `<span class="x4-logo" data-t="190×4">190<span class="x4-x">×4</span></span>`
  (вариант hero — добавить класс `x4-logo--display`).
- **Реализация в Steam:** в DOM Steam логотипа-текста нет — это надо вставить через
  `webkit.js` (найти контейнер титулбара слева и заменить/дополнить). Полная спецификация и
  все размеры — в `Logo.html` и в блоке `.x4-logo` в `theme.css`.
- **Фон:** только тёмный. На светлом призраки и «×4» гаснут — там логотип не использовать.

### Раскладка по экранам (детально)

**Каркас окна (`.x4-app`, общий для Store/Library/Game/Downloads/Community):**
- `display:flex; flex-direction:column; width:1920px; height:1080px;`
- Сверху `<header class="x4-chrome">`: титулбар 36px + строка навигации 52px (+ опц. url-бар 28px).
- Центр `.x4-app__body { flex:1; display:flex; }` — сайдбар + контент или вертикальный контент.
- Снизу футер 34px (`Добавить игру` · `Управление загрузками` · `Друзья и чат`).
- Титулбар собирается скриптом `chrome.js` (функции `titlebar()`, `nav()`, `footer()`).

**Library** — сайдбар 300px (поиск, дропдаун «Игры и Программы», коллекции «Избранное»/«Без
категории» со списком строк) + main: полка «Что нового» (горизонтальный скролл карточек
288px), сетка капсул `repeat(5,1fr)`, gap 18px, соотношение `3 / 4.3`, hover —
`translateY(-4px)` + красный glow + красная рамка.

**Game** — hero 380px (арт + два градиентных veil слева/снизу + логотип игры). Под hero
строка действий: слева красная кнопка «Играть» (`.x4-btn--primary.x4-btn--lg`), затем 4
стата (облако/последний запуск/наиграно/достижения) с красными иконками-плашками, справа
gear/info/heart. Ниже табы магазина. Тело — грид `1fr 384px` (лента активности слева,
сайдбар справа: друзья, заметки, XP-карточка, коллекционные карточки, DLC).

**Downloads** — активная закачка как hero-карточка: справа readout (Сеть/Макс/Диск),
live-график (SVG-полилиния с красным `drop-shadow`), снизу прогресс-бар + красная кнопка
паузы. Ниже секции «Далее» (пусто) и «Запланировано» (строки `.dl-row`).

**Settings/Friends/Chat** — плавающие окна `.x4-window` со своим титулбаром
(`.x4-window__bar` 38–40px + win-кнопки; close hover = `--accent-dim`).

## 6. Дизайн-токены (копировать как есть — это `:root` темы)

```css
:root{
  /* surfaces */
  --bg-0:#07090d; --bg-1:#0d1016; --bg-2:#11151d; --bg-3:#161b25;
  --line:rgba(255,255,255,.06); --line-2:rgba(255,255,255,.10);

  /* brand accent — КРАСНЫЙ = успех / активно / connected / Play */
  --accent:#ff2530; --accent-dim:#b3121b; --accent-deep:#4a0a0f;
  --accent-soft:rgba(255,37,48,.12); --accent-line:rgba(255,37,48,.40);
  --accent-glow:0 0 12px rgba(255,37,48,.55);
  --accent-glow-lg:0 0 22px rgba(255,37,48,.45),0 0 4px rgba(255,37,48,.8);

  /* text */
  --text-hi:#e8edf4; --text-md:#b6bfcd; --text-lo:#8a93a3; --text-dis:#555c6a;

  /* status (зелёный — ТОЛЬКО точка «в сети») */
  --status-online:#38e07b; --status-ingame:var(--accent);
  --status-offline:#59616f; --warn:#ffb020;

  /* geometry */ --r-sm:2px; --r-md:3px; --r-lg:5px; --hair:1px;

  /* type */
  --f-display:'Orbitron',sans-serif;   /* ТОЛЬКО лого + верх. навигация */
  --f-ui:'Saira',sans-serif;           /* весь UI и тело */
  --f-cond:'Saira Semi Condensed','Saira',sans-serif; /* плотные лейблы */

  /* elevation */
  --sh-1:0 1px 0 rgba(255,255,255,.03) inset,0 2px 8px rgba(0,0,0,.45);
  --sh-2:0 18px 50px rgba(0,0,0,.65),0 2px 0 rgba(255,255,255,.03) inset;
  --sh-win:0 30px 90px rgba(0,0,0,.7),0 0 0 1px rgba(0,0,0,.6);

  --ease:cubic-bezier(.2,.7,.3,1);
}
```

**Шрифты.** Orbitron (500–800), Saira (300–700), Saira Semi Condensed (400–700) — через
Google Fonts `@import` (см. шапку `theme.css`). Логотип «×4» использует доп. красные
`#8c0d14` / `#c01622`; glitch-призраки — `#ff2530` / `#27e0ff`.

**Типографическая шкала (фактическая):**
- Лого/верх. навигация — Orbitron, 14–17px (нав), 600–900.
- H1 экрана — Saira 700, 26–30px.
- Заголовки-таблички секций — Saira Semi Condensed 600, 12px, `letter-spacing:1.5–2px`, UPPERCASE.
- Тело/списки — Saira 400–500, 13–14px.
- Мелкие лейблы/мета — 11–12.5px, `--text-lo`/`--text-dis`.

**Радиусы:** только 2 / 3 / 5px. **Границы:** 1px hairline. **Тени:** `--sh-1/2/win` + неон `--accent-glow*`.

## 8. Иконки

Иконки — инлайновые SVG (stroke, сетка 24px), генерируются `icons.js` из объекта `x4icons`
(плейс через `<i data-ic="имя">`). Стиль строгий, геометричный, `stroke-width≈1.7`,
`round` концы. Полный набор имён — в `icons.js` (search, filter, play, gear, download,
people, trophy, cloud, controller, mic и т.д.). В реальной теме Steam свои иконки — заменять
их по необходимости через CSS `mask`/`background` или JS-инъекцию; наш набор — эталон стиля.

## 9. Манифест Millennium (`theme.json`) — пример

Точную схему сверять с актуальной документацией Millennium, общая форма:
```json
{
  "name": "190x4",
  "description": "Cyberpunk command-center red-neon theme",
  "author": "190x4",
  "Steam": {
    "TargetCss": "webkit.css",
    "TargetJs":  "webkit.js"
  },
  "UseDefaultPatches": true
}
```
`webkit.css` инжектится во все webkit-окна Steam (главное окно, оверлей, друзья/чат).
`webkit.js` — для DOM-инъекций (логотип-вордмарк, glitch-разметка, кастомные бейджи).

## 10. Взаимодействия и поведение

- **Hover везде даёт неоновую обратную связь** (рамка/glow/подсветка), переход
  `.15s var(--ease)` (`cubic-bezier(.2,.7,.3,1)`).
- **Кнопка «Играть»** — самый яркий элемент: красный градиент + `--accent-glow`, на hover
  `--accent-glow-lg` + `brightness(1.06)`, на active — `brightness(.94)` + inset-тень.
- **Капсулы/карточки игр** — на hover поднимаются (`translateY(-2…-4px)`) + красная рамка + glow.
- **Прогресс загрузки** — красный градиент с бегущей диагональной штриховкой.
- **Glitch на логотипе** — статичный по умолчанию, усиление сдвига призраков на `:hover`.
  Не зацикливать анимацию (без бесконечных декоративных лупов).
- **prefers-reduced-motion** — отключать glow-пульсации/сдвиги, оставлять статичные состояния.

## 11. С чего начать (порядок реализации)

1. Поставить Millennium, включить dev-режим, открыть DevTools клиента Steam.
2. Создать `themes/190x4/` + `theme.json`, подключить пустой `webkit.css` — убедиться, что
   инъекция работает (например, перекрасить `body` фон в `--bg-0`).
3. Перенести `:root`-токены (§6) и подключить шрифты.
4. Идти по экранам сверху вниз: титулбар → навигация → магазин/библиотека → страница игры →
   загрузки → окна. Для каждого: снять селектор в DevTools, применить соответствующий `.x4-*`
   стиль, сверить с HTML-референсом пиксель-в-пиксель.
5. Логотип и любые новые элементы DOM — через `webkit.js`.
6. Регулярно сверять семантику цвета (§3): красный=актив/успех, зелёный — только online-точка.

**Шрифты** — Google Fonts (Orbitron, Saira, Saira Semi Condensed), подключены `@import` в
`theme.css`. Для автономной темы можно перейти на self-host — инструкция, таблица весов и
готовый `@font-face`-шаблон лежат в `assets/fonts/README.md` (бинарные `.woff2` в бандл не
вложены, их нужно скачать — путь и утилита указаны там же).

**Иллюстрации/обложки** в бандл не входят — в референсах арт капсул/баннеров заменён
плейсхолдерами (`.x4-art` + `.x4-scan`/`.x4-hex`). Реальные обложки игр в клиенте
подставляет сам Steam — тема их не трогает, только обрамляет (рамки, hover-glow,
градиентные veil).
